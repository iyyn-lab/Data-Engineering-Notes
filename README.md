# Data-Engineering-Notes

A centralized repository for Data Engineering learning materials, shared as Markdown notes. Covers core concepts, tools, and modern data stack knowledge (Python, SQL, Spark, Cloud, etc.) to build a strong technical foundation and promote continuous learning within the team.

---

## 🗺️ The Complete Data Engineering Roadmap (Visual Guide)

To see exactly *what* to learn and *when* to learn it, we use an interactive visual roadmap created by **Gowtham SB**.

**Website Link:** [https://www.tablenotfound.com/learn/de_road_map.html](https://www.tablenotfound.com/learn/de_road_map.html)

### 🧭 How to use this Roadmap:
- It acts as a **Checklist / Mind Map**.
- You can click on any node (like "Python" or "SQL") to see the exact sub-topics you need to master.
- Use it as a **"Topic Dictionary"**: if you feel lost, open the website, expand the branch, and see what you have missed!

### 📚 Topics Covered in this Roadmap:

| Branch | Key Sub-Topics |
| :--- | :--- |
| **Linux** | Basic commands (`cd`, `ls`), File Handling (`grep`, `awk`), Process Handling (`ps`, `kill`). |
| **SQL** | From basic `SELECT` to advanced `Window Functions`, `CTEs`, and `Indexing`. |
| **Python** | OOP, File Handling, DataFrames, and API connectivity. |
| **Big Data** | Hadoop (Legacy), Spark (RDDs, DataFrames), and Streaming. |
| **Cloud** | AWS, GCP, and Azure services. |
| **Airflow** | Workflow orchestration. |
| **AI for Data Engineers** | MCP, RAG, and Open Source Models (Advanced topics for the future). |

---

## 🚀 My Learning Strategy
1. Start with the **Python** and **SQL** branches on the website.
2. Master the **Linux** branch (since you need it for server management).
3. Don't jump into **Big Data (Spark)** until you are very comfortable with Python.
4. Use the website as a "Topic Dictionary" to stay on track.

---

*Data Engineering is an Evergreen field because data will always exist, and someone will always need to manage it.*
